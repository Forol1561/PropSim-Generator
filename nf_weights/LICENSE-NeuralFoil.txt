The files in this directory are the neural-network weights of NeuralFoil 0.3.3
(https://github.com/peterdsharpe/NeuralFoil), by Peter Sharpe, used by sectionfoil.py.
Changes: only the first four network outputs (analysis confidence, CL, CD, CM) are used, so the
output layer of each network is truncated to those rows; the arrays are otherwise copied unchanged
(float32). The network inference in sectionfoil.py is a NumPy re-implementation of NeuralFoil's
get_aero_from_kulfan_parameters(), and its Kulfan (CST) airfoil fit re-implements the method of
AeroSandbox's get_kulfan_parameters() / Airfoil.normalize() (https://github.com/peterdsharpe/AeroSandbox).
